[h1]ApocalipseBR - Regiões[/h1]

Region management for Project Zomboid Build 42 multiplayer servers. Create zones with custom PVP rules, zombie overrides, boss zombies, and sprinter screams.

[hr][/hr]

[h2]Features[/h2]

[h3]Zone System[/h3]
[list]
[*] Create zones anywhere on the map with custom rules
[*] Zone types: PVP, Sprinters, Shamblers, Safe Zone, Loot Bonus, Dead Zone, Custom
[*] Auto-generated safe zones fill the entire map - no gaps
[*] Overlapping zones merge smartly
[*] Edit zones via .txt config file or admin Panel - no code needed
[*] Admin panel for editing, creating and teleporting to regions
[*] Players can see the regions through the admin panel but they can't edit or create regions
[/list]

[h3]PVP Zones[/h3]
[list]
[*] PVP auto-enables when entering PVP zones, auto-disables when leaving
[*] Anti-exploit: rapid safety toggling triggers a lockout
[/list]

[h3]Per-Zone Zombie Overrides[/h3]
Set percentage chances (0-100%) per zone for:
[list]
[*] Speed (Sprinter / Shambler), Vision, Hearing, Toughness, Strength, Memory, Cognition
[*] Zombie armor and tough zombie extra hits (1-99)
[/list]

[h3]Boss Zombies[/h3]
[list]
[*] Register boss zombie types by outfit - guaranteed stats, custom health, theme music, sound effects
[*] Other mods can register their own boss modules via the API
[/list]

[h3]Sprinter Screams[/h3]
Based on SIMBAproduz's "theySEE YOU", enhanced and integrated:
[list]
[*] Sprinters scream on discovery, close-up, and during chases
[*] 62 unique voice files - no repetition
[*] Screams attract nearby zombies (horde pull)
[*] Configurable via sandbox options (chances, volumes, ranges, cooldowns)
[/list]

[h3]Sprinter Animations[/h3]
[list]
[*] Custom lunge and movement animations for sprinters
[*] 5 sprint variants with multiplayer sync
[/list]

[h2]How To Add Regions (Admin Panel)[/h2]
This mod includes an in-game map picker so server admins can create regions without editing code.

[h3]Step-by-step[/h3]
[list]
[*] Join your server with an admin account.
[*] Right click anywhere in the ground to open the context menu, open the Regions Admin Panel and choose Create New Region.
[*] In the map picker, click the map to set Point 1 (first corner), then click again to set Point 2 (second corner).
[*] Fill in the form (name, flags, zombie properties, maxHits, and optional message).
[*] Click Submit to create the region.
[*] Use the admin region list to review, test, and teleport to your new region.
[/list]

[h3]Configuration Tips[/h3]
[list]
[*] Start simple: set Name + PVP Zone first, then tune zombie stats in small increments.
[*] Percent values are chances (0-100) per property and are evaluated using one random roll.
[*] If conflicting chances are both 100% (for example 100% sprinters and 100% shamblers), the first matching rule in evaluation order will always win.
[*] maxHits applies only when a zombie rolls as Tough; it defines extra hits absorbed before the zombie starts taking normal damage.
[*] Keep entry/exit announcements enabled while testing so players can confirm region boundaries.
[/list]

[h3]Recommended Workflow For Live Servers[/h3]
[list]
[*] Create the region in a low-population period.
[*] Teleport to edges and verify boundaries before announcing it to players.
[*] Apply one gameplay change at a time (PVP, then speed, then senses, etc.) and monitor results.
[/list]
